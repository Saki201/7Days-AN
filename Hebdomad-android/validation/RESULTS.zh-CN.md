# 2026-11-17 测试结果

测试系统：Android 7.0/API24 ARMv7 系统镜像，classic Android ARM 软件模拟器，OpenGL ES 2.0 SwiftShader，屏幕 480×320。没有连接实体安卓手机。

已验证：

- APK 使用 Android build-tools 35.0.1 签名检查，v1/v2/v3 验证通过；adb 安装成功。
- 首次复制并校验原 ARM 引擎与用户资源包。引擎加载后报告 3,322 个资源、67 件物品、65 个文件、581 条系统文字。
- 原 ARM 静态初始化、原 main 入口、主菜单三维场景正常运行。
- 通过触屏 W/J 选择并开始 New Game，进入第一天开场动画及 `day1/2008` 房间。
- 触屏 J 推进对话，W 移动人物，K 打开物品、M 打开地图，打开 SYSTEM 设置页。方向按钮的长按会触发原游戏菜单重复选择；短按若遇到极低帧率可能漏过，测试中较长按压可可靠响应。
- 音频设备以 12,000 Hz 单声道 S16LE 初始化，SDL 队列输出超过两秒 PCM。没有进行人工听音验证。
- 房间打字机处触屏 J 打开 Save Game，保存第一槽，界面显示 Game Saved!；生成 45,742 字节 slot1.json，并通过 JSON 解析。
- Home 切后台，重新打开后恢复原画面，日志有 nativePause/nativeResume，无此次恢复崩溃。
- 强制停止并更新安装最终 APK，启动 Load Game，第一槽显示 Data 1 / 1st Day，确认后回到保存位置。最终截图 `09-loaded-final-build.png` 显示最终按钮布局。

截图 01—08 来自前一测试构建，其 native 代码与最终构建相同；最终构建仅修正按钮文字并增加 Escape 返回键。09 和 final-* 日志来自最终 APK。

未验证：第二天及后续关卡、战斗、全部资源动态使用、完整通关、实体手机性能、Android 新版本、arm64-only 设备（不支持此版）、多指同时按压的设备端效果、长期后台进程回收后的无存档恢复。

因此该交付是可启动并经过开场/存读档验证的实验移植，不是所有设备和全流程保证正常的完成品。原引擎完整源码仍未重建；交付的是原 ARM 二进制和新增平台适配源码。未使用 Vita3K，也没有生成替代游戏或展示假菜单。

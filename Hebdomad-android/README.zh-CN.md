# Hebdomad 安卓 ARMv7 中文修订版 0.5

这是可独立安装、内含用户提供资源包的 Android APK。无需 Vita3K 或另一款应用。

## 实现范围

此项目通过逆向分析，为发布版 ARM Linux 引擎重写安卓平台接口。原游戏逻辑仍以 `assets/engine.arm` 中的机器码执行，不进行 CPU 模拟。新增 Java/C++ 源码可编译；`reverse-engineering/recovered.c` 是分析用伪代码，不能直接编译，也不是原作者源码。项目没有完成整个游戏引擎的源码重建。

适配代码负责加载原 ELF、重定位导入、部分 GLIBC/Bionic ABI 转换、SDL3 函数表替换、安卓 GLES 上下文和音频输出。资源包首次启动会校验 SHA-256 并复制到应用私有目录，后续启动保留存档。

## 安装和操作

安装提供的 APK，打开 Hebdomad，等待首次准备数据。资源包已经内置。使用左侧摇杆选择菜单，再按右侧“动作”确认。

- 八向摇杆：移动及菜单选择，支持斜向、死区和多点触控。
- 确认/动作：J，选择、交互和推进对话。
- 物品/返回：K，打开物品界面或返回。
- 地图：M。
- 返回：Escape。

触屏支持多个手指同时按键；切到后台会释放所有按键。开场和对话期间部分操作由原游戏暂时禁用。短按会在原生层保留到游戏读取输入；“画面”按钮打开滤镜选择，设置自动保存。

## 兼容边界

APK 仅包含 `armeabi-v7a`，需要系统支持 32 位 ARM 应用。仅支持 arm64 的设备不能安装或运行此版。声明最低 Android 5.0，实际测试包括 Android 7.0/API24 ARMv7 软件模拟器及用户的雷电 9 横屏窗口（2560×1440）。其他 Android 版本、实体手机、后续全部关卡和通关流程未经验证。不能承诺所有设备正常运行。

测试截图、日志和逐项结果见 `validation/`。当前版本使用开发签名并开启调试，便于取得错误日志。加载器要求原地址空间可用；若系统拒绝内存执行或地址被占用，会明确报错。部分未调用的 Linux 平台导入仍保留诊断中止处理。

内置用户归档中的中文备份包（SHA256：501dac61d826dd5587c7a12f50590e62167592bff89897ed44bdf5b19ccb5435）。修复原引擎只识别有限拉丁字形导致中文字形丢失的问题：为原始位图分配一致的私用区码点，剧情解析和字体图集共享映射，不做 OCR。菜单中文已实测，所有剧情仍需进一步验证。

声音修复：原 N900 引擎主动将 SDL 音频驱动设为 dummy；安卓适配层拦截此设置，使用 AAudio/OpenSL ES 输出。已验证 OpenSL ES 设备打开、非静音 PCM 和队列消耗，未在实体手机试听。音量键控制媒体音量。

画面：关闭原引擎 320×240 低清模式，按屏幕尺寸渲染。1× 为屏幕原生尺寸，2× 为场景超采样；雷电 2560×1440 下实际场景缓冲为 5120×2880，受 GPU 上限及 6144 像素边长限制。原有低清纹理和位图文字不会因此增加原始细节。

比例：自动适配横屏、16:9、4:3、5:3；3D 投影按宽高比修正，UI 横向比例也作修正。自动适配使用屏幕比例，更宽屏幕尚未实测。

滤镜：原始、xBR、HQ2x、Dot 点阵、扫描线。全尺寸帧后处理；Dot/扫描线按屏幕像素绘制细小图案。xBR/HQ2x 边缘修整在高分辨率 3D 画面中的变化仍然偏轻，不将其视为高清素材重制。

触控面板改为带阴影、金属边缘、高光、不同颜色实体按键和按下反馈的摇杆及 AB 键簇；多点触控和原键位映射保留。点击“画面”→“虚拟按键调节”可以分别调整透明度（10%—100%）和大小（50%—160%），点击“拖动位置”可拖动摇杆及每个按键，点击顶部提示或返回键保存；“恢复默认”清除自定义布局。调节后的按键会被限制在屏幕内，避免放大后触控区域跑出屏幕。

## 从源码构建

Windows PowerShell，安装 Python 3、JDK 21、Android SDK platform android-35 / build-tools 35.0.1、NDK r27d，然后执行：

```powershell
$env:ANDROID_SDK_ROOT='你的 Android SDK 目录'
$env:ANDROID_NDK_HOME='你的 NDK r27d 目录'
$env:JAVA_HOME='你的 JDK 21 目录'
python build.py
```

输出为 `build/Hebdomad-experimental.apk`。构建脚本创建自己的开发签名私钥；交付源码不包含本次签名私钥，所以自行构建的 APK 更新安装时可能需要卸载原包（卸载会删除应用存档）。

`third_party/SDL3-3.4.20.aar`、头文件及 dynapi 表已经附带。其他构建工具未打包。`assets/engine.arm` 与 `assets/res.spk` 也已包含，便于重现本次构建。

## 来源与许可

原发布仓库：https://github.com/0x4d696e68/Hebdomad ，原 ELF 从 v1.1.0 DEB 提取；数据来自用户提供的七夜数据包。原游戏及移植发布物的权利仍归相应权利人，此交付不授予其再分发许可。

SDL3 使用 zlib 许可，见 `third_party/SDL-LICENSE.txt`。原程序静态链接了 C++ 运行库；新增适配库通过 Android NDK 的 libc++ 构建。反编译文件仅用于分析，并保留来源说明。

滤镜源码来源：libretro/glsl-shaders 的 xbr/shaders/xbr-lv2.glsl（Hyllian）和 hqx/shader-files/hq2x-halphon.glsl（Lior Halphon / hunterk），MIT 许可保留在 third_party/filters 中。prepare_shaders.py 将矩阵和位运算改写为 GLES 2.0 兼容的等价表达式。
